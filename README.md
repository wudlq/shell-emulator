# Эмулятор командной оболочки (вариант 6)

## Общее описание

Консольное приложение на Python, которое имитирует работу командной
строки UNIX-подобной ОС. Эмулятор работает с виртуальной файловой
системой (VFS), которая загружается из JSON-файла и целиком хранится
в памяти: сам файл VFS никогда не изменяется. Приглашение к вводу
содержит имя VFS и текущий каталог, например `deep:/$ `.

Структура проекта:

| Путь | Что там |
|---|---|
| `src/main.py` | точка входа, параметры командной строки |
| `src/shell.py` | цикл REPL и выполнение стартового скрипта |
| `src/lexer.py` | разбор строки на слова (кавычки, комментарии) |
| `src/vfs.py` | VFS в памяти и загрузка её из JSON |
| `src/commands.py` | команды эмулятора |
| `tests/` | скрипты проверки, стартовые скрипты, примеры VFS |

## Функции и настройки

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к JSON-файлу VFS |
| `--script PATH` | путь к стартовому скрипту |

При запуске выводятся значения всех параметров (`[debug] ...`).
Без `--vfs` создаётся пустая VFS с именем `vfs`.

### Формат VFS

```json
{
  "name": "myvfs",
  "root": {
    "type": "dir",
    "children": {
      "hello.txt": {"type": "file", "data": "0J/RgNC40LLQtdGCIQo="},
      "docs": {"type": "dir", "children": {}}
    }
  }
}
```

- `type` — `dir` (каталог) или `file` (файл);
- `data` — содержимое файла в base64 (подходит и для двоичных данных),
  длинное значение можно разбить на список строк;
- `name` — имя VFS для приглашения (по умолчанию имя файла);
- `mtime` — время изменения в секундах Unix (необязательно).

Ошибки загрузки (нет файла, не JSON, неверный base64, корень не
каталог) выводятся на экран, эмулятор завершается с кодом 1.

### Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку. Комментарии
как в Python: всё после `#` игнорируется (если `#` не внутри кавычек).
При выполнении на экран выводится и команда, и её результат. После
скрипта эмулятор переходит в интерактивный режим, если не было `exit`.

### Команды

- Парсер разбивает строку на слова по пробелам. Текст в одинарных или
  двойных кавычках считается одним аргументом.
- `ls`, `cd` — заглушки, выводят своё имя и аргументы.
- `vfs-info` — служебная команда: имя VFS, число каталогов и файлов,
  общий размер файлов.
- `exit` — выход из эмулятора.
- Ошибки: неизвестная команда, незакрытая кавычка, лишние аргументы.

## Сборка и запуск тестов

Сборка не нужна, требуется Python 3.8+.

```sh
./run.sh                                  # запуск эмулятора
./run.sh --vfs tests/vfs/deep.json --script tests/scripts/stage3.txt
./tests/test_repl.sh      # этап 1: REPL
./tests/test_params.sh    # этап 2: параметры командной строки
./tests/test_vfs.sh       # этап 3: разные варианты VFS
```

Примеры VFS в `tests/vfs/`: `minimal.json` (пустой корень),
`files.json` (несколько файлов, есть двоичный), `deep.json` (больше
трёх уровней вложенности), а также файлы с ошибками.

## Примеры использования

```
$ ./run.sh --vfs tests/vfs/deep.json
[debug] vfs = tests/vfs/deep.json
[debug] script = None
deep:/$ vfs-info
имя VFS: deep
каталогов: 10
файлов: 6
размер файлов, байт: 737
deep:/$ foo
foo: команда не найдена
deep:/$ exit
```
