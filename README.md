# Эмулятор командной оболочки (вариант 6)

## Общее описание

Консольное приложение на Python, которое имитирует работу командной
строки UNIX-подобной ОС. Приглашение к вводу содержит имя VFS.

Весь код находится в файле `src/main.py`, в папке `tests/` — скрипты
для проверки работы.

## Функции и настройки

Параметры командной строки:

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |

При запуске выводятся значения всех параметров (`[debug] ...`).

Стартовый скрипт — текстовый файл с командами эмулятора, по одной на
строку. Комментарии как в Python: всё после `#` игнорируется (если `#`
не внутри кавычек). При выполнении на экран выводится и команда, и её
результат. После скрипта эмулятор переходит в интерактивный режим,
если в скрипте не было `exit`.

Команды и парсер:

- Парсер разбивает строку на слова по пробелам. Текст в одинарных или
  двойных кавычках считается одним аргументом.
- `ls`, `cd` — заглушки, выводят своё имя и аргументы.
- `exit` — выход из эмулятора.
- Ошибки: неизвестная команда, незакрытая кавычка, лишние аргументы.

## Сборка и запуск тестов

Сборка не нужна, требуется Python 3.8+.

```sh
./run.sh                  # запуск эмулятора
./run.sh --vfs myvfs.json --script tests/scripts/stage2.txt
./tests/test_repl.sh      # проверка REPL
./tests/test_params.sh    # проверка параметров командной строки
```

## Примеры использования

```
vfs:/$ cd "my folder"
cd ['my folder']
vfs:/$ foo
foo: команда не найдена
vfs:/$ exit
```
